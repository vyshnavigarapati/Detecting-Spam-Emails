# 📧 Detecting Spam Emails  

## 🔹 Project Overview  
This project focuses on building a Machine Learning model to classify emails as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) techniques. The goal is to automatically filter unwanted emails and improve email security and user experience.

---

## 🔹 Problem Statement  
Spam emails create security risks and reduce productivity. This project aims to develop an intelligent classification system that accurately detects and filters spam messages.

---

## 🔹 Dataset  
- Labeled email dataset containing spam and ham messages  
- Preprocessed using text cleaning and NLP techniques  

---

## 🔹 Technologies Used  
- Python  
- NumPy  
- Pandas  
- Scikit-learn  
- Natural Language Processing (NLP)  
- TF-IDF Vectorization  
- Jupyter Notebook  

---

## 🔹 Project Workflow  
1. Data Collection  
2. Data Cleaning (removal of stopwords, punctuation, special characters)  
3. Text Preprocessing (stemming/lemmatization)  
4. Feature Extraction using TF-IDF  
5. Model Training  
   - Naive Bayes  
   - Logistic Regression  
   - Support Vector Machine (SVM)  
   - Random Forest  
6. Model Evaluation using Accuracy, Precision, Recall, F1-Score  

---

## 🔹 Results  
The model successfully classifies spam and non-spam emails with high accuracy and good precision-recall balance.
